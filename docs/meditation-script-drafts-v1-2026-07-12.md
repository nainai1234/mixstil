# 冥想引导脚本草案 V1

日期：2026-07-12  
状态：待内容从业者审核，禁止直接作为公开生产内容。  
用途：把公开专业内容中观察到的“状态识别 -> 单一动作 -> 留白 -> 人声退出”结构转化为 DeepNill 自有脚本。

## 使用规则

- 每句话只包含一个动作。
- 不使用治疗、保证、诊断、清除创伤或强制暗示。
- 不要求用户屏息、强行改变呼吸或完成困难动作。
- 句子之间保留真实留白；留白由背景声承接。
- 下面的秒数是编排草案，不是医学标准。

## A. 睡前身体扫描（Bedtime Body Scan）

目标：帮助用户从“准备睡觉”过渡到身体感受。  
建议长度：8-10 分钟。  
背景：无歌词、低动态、极轻环境层；人声约占前 3-4 分钟，之后退出。

| ---: | --- | --- | ---: |

| 00:27 | breath | 不需要改变呼吸，只要注意它正在发生。 | 8s |
| 00:43 | feet | 感受双脚与下方支撑接触的地方。 | 8s |
| 01:02 | ankles | 让脚踝不必再用力。 | 8s |
| 01:20 | legs | 感受小腿和大腿逐渐变得安静。 | 10s |
| 01:42 | hands | 让双手放在舒服的位置。 | 8s |
| 02:00 | shoulders | 发现肩膀现在的重量。 | 10s |
| 02:20 | jaw | 让下巴和脸颊保持柔软。 | 10s |
| 02:42 | chest | 感受胸口随着呼吸轻轻移动。 | 12s |
| 03:08 | release | 接下来不需要继续跟随指令。让背景声陪你休息。 | 20s |
| 03:28 | exit | 人声退出，背景继续至结束。 | - |

## B. 夜醒回睡（Return to Sleep）

目标：减少信息和任务感，避免把用户重新唤醒。  
建议长度：5-8 分钟。  
背景：稳定低动态底层；不使用水滴、鸟叫、铃声或强旋律，除非用户明确要求。

### 中文

| 时间 | 事件 | 文案 | 句后留白 |
| ---: | --- | --- | ---: |
| 00:20 | permission | 你现在不需要解决任何事情。 | 10s |
| 00:40 | position | 保持当前舒服的姿势。 | 12s |
| 01:02 | exhale | 只注意下一次自然的呼气。 | 14s |
| 01:28 | sound | 让背景声在远处持续，不需要追随它。 | 14s |
| 01:56 | return | 如果思绪回来，也不必把它推开。 | 16s |
| 02:28 | release | 接下来只保留安静的呼吸和背景声。 | 24s |
| 02:52 | exit | 人声退出；背景继续。 | - |

### English

| Time | Event | Copy | Pause |
| ---: | --- | --- | ---: |
| 00:20 | permission | There is nothing you need to solve right now. | 10s |
| 00:40 | position | Stay in the position that feels comfortable. | 12s |

## C. 短时压力安放（Short Stress Settling）

目标：为 5-10 分钟的短时放松提供清晰、非治疗性的注意力转移。  
背景：自然声或低刺激氛围，避免强音乐起音。

### 中文

| 时间 | 事件 | 文案 | 句后留白 |
| ---: | --- | --- | ---: |
| 00:10 | orientation | 先找到一个可以让身体停下来的位置。 | 6s |
| 00:24 | contact | 注意身体与椅子或地面的接触。 | 8s |
| 00:42 | breath | 让吸气自然进来，让呼气自然离开。 | 10s |
| 01:04 | sound | 听见离你最近的声音。 | 8s |
| 01:22 | distance | 再听见更远处的声音。 | 10s |
| 01:44 | choice | 这一刻不需要做出决定。 | 12s |
| 02:08 | release | 继续用自己的节奏停留片刻。 | 20s |
| 02:28 | exit | 人声退出；背景继续到会话结束。 | - |

### English

| Time | Event | Copy | Pause |
| ---: | --- | --- | ---: |
| 00:10 | orientation | First, find a position where your body can pause. | 6s |
| 00:24 | contact | Notice where your body meets the chair or the floor. | 8s |

| 01:04 | sound | Notice the sound that is closest to you. | 8s |

| 02:08 | release | Stay here for a little while in your own rhythm. | 20s |
| 02:28 | exit | Voice exits; background continues to the end. | - |
