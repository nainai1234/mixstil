## Release Gates

1. Source and license captured.
2. Commercial derivative use allowed.
3. Raw redistribution disabled unless explicitly permitted.
4. SHA-256 stored.
5. Audio decodes and reports expected duration/sample rate.
6. Loudness, clipping, and sudden-transient checks pass.
7. Human listening QA assigns recommended scenes and default volume.
8. Only then set `qa_status = approved` and expose it to creators.
