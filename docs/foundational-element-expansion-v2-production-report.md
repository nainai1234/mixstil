## Production And QA

All 60 candidates were generated by real paid calls to
`google-cloud-vertex-ai` using `lyria-3-clip-preview`. Raw outputs are retained
for lineage verification.

Machine analysis found that 58 raw outputs were too close to the digital
ceiling for direct inventory use. The preparation pipeline therefore:

- normalized every prepared candidate to a conservative peak;
- built a two-second crossfaded unit for loopable categories;
- isolated the first prominent onset for one-shot accents;
- retained raw and prepared audio as separate files;
- recalculated onset density, spectral centroid, RMS variation, peak, and
  technical flags.

Prepared result:

- 54 candidates passed the current automated technical screen;
- 6 candidates remain technically flagged for possible multiple onsets;
- all 60 remain blocked on human element-identity and no-human-voice review;
- no candidate has been registered as an approved runtime Stem.

The six technical flags are in the singing-bowl and wood-chime families. A
resonant partial can produce multiple detected onsets without representing a
second physical strike, so listening is required rather than automatic
rejection.
