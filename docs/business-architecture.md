# 产品架构与商业逻辑

> 历史文档，已于 2026-07-14 被
> [ToC Product Development Master Plan](./toc-product-development-master-plan.md)
> 和 [Project Mainline Charter](./project-mainline-charter.md) 替代。本文中的小 B、创作者优先商业路径不再是当前最高指示。

## 1. 核心战略

不要先做一个“平台感很重”的疗愈内容订阅 App。先做一个足够好用的睡前声景制作工具，让用户完成作品、生成分享页、带到自己的渠道传播。

平台真正要验证的不是“用户愿不愿意听平台给的内容”，而是：

- 创作者是否愿意用工具制作作品。
- 创作者是否愿意主动分享作品。
- 听众是否愿意在分享页停留和复听。
- 真实数据是否能筛出值得入库的作品。
- 创作者是否愿意为更好制作、更好传播、更好数据付费。

产品的商业飞轮：

```text
工具降低制作门槛
  -> 创作者产出更多作品
  -> 分享页带来自然流量
  -> 数据筛选优质作品
  -> 平台精选提升内容质量
  -> 好作品吸引更多听众和创作者
  -> 创作者为素材、能力、传播和数据付费
```

## 2. 用户分层

### 2.1 普通听众

典型场景：

- 睡前想找一段安静、不刺耳、不打扰的声音。
- 半夜醒来想快速回到稳定状态。
- 工作后想要短时间放松。
- 朋友或博主分享了一首作品，点开试听。

核心诉求：

- 不想复杂选择。
- 不想被强刺激内容打断。
- 希望声音稳定、柔和、可重复听。
- 希望收藏之后下次容易找到。

付费可能性：

- 首版不应强推听众付费。
- 听众付费应放在精选内容池成熟之后。
- 早期听众的价值主要是播放、收藏、完播和传播数据。

### 2.2 轻创作者

典型人群：

- 情绪陪伴博主。
- 冥想/瑜伽/身心灵内容创作者。
- 播客主。
- 睡眠、生活方式、个人成长类账号。
- 想送朋友一段声音礼物的普通用户。

核心诉求：

- 我没有音乐制作能力，但想做出“像样”的声音作品。
- 我需要作品适合分享，而不是只存在本地。
- 我想知道别人有没有听、有没有喜欢。
- 如果表现好，我希望被平台看见。

付费可能性：

- 愿意为更好的模板、素材、时长、封面、分享页和数据付费。
- 不一定马上为“疗愈内容”付费，但会为“让我的作品更好看、更好听、更好传播”付费。

### 2.3 专业/半专业创作者

典型人群：

- 声音疗愈师。
- 冥想老师。
- 瑜伽老师。
- 心理陪伴类内容经营者。
- 音频制作人。

核心诉求：

- 需要稳定地发布作品。
- 需要经营个人主页。
- 需要查看作品数据。
- 需要把作品沉淀成系列。
- 未来希望获得打赏、售卖、分成或课程承接。

付费可能性：

- 高于轻创作者。
- 会为品牌化主页、系列管理、高级数据、外链追踪、导出和商业授权付费。

### 2.4 平台运营者

核心诉求：

- 控制版权风险。
- 控制医疗化表达风险。
- 控制低质量 UGC 污染。
- 找到值得推荐的作品。
- 逐步建立内容库和商业市场。

平台不应在早期承担过重的内容生产压力，而是用工具和分享数据让市场帮忙筛选。

## 3. 业务对象架构

### 3.1 Sound Asset 声音素材

平台提供的基础生产资料。

字段：

- 名称。
- 类型：自然声、氛围音、节奏、钟声、人声、白噪音。
- 授权状态。
- 商用范围。
- 可否二创。
- 可否用于公开分享。
- 可否用于付费作品。
- 情绪标签。
- 场景标签。
- 推荐音量范围。
- 推荐循环方式。

关键逻辑：

- 素材是平台早期最核心资产之一。
- 素材必须先合规，再开放给创作者使用。
- 免费素材负责降低上手门槛，付费素材负责订阅转化。

### 3.2 Template 方法论模板

模板不是简单预设，而是“场景化制作方法”。

字段：

- 场景：睡前放松、夜醒回睡、情绪安放、冥想呼吸、纯自然声。
- 推荐时长。
- 默认素材组合。
- 层级结构。
- 人声建议。
- 节奏建议。
- 禁止表达提醒。
- 适合人群。
- 预期听感。

关键逻辑：

- 模板降低制作门槛。
- 模板保证作品质量下限。
- 模板可以作为付费点。
- 模板帮助平台统一内容风格，避免作品变成杂乱音乐生成。

### 3.3 Work 声景作品

创作者生成并管理的核心内容。

状态：

- Draft：草稿。
- Private：仅自己可见。
- Shared：已生成公开分享页。
- Reviewable：达到申请入库门槛。
- Submitted：已申请审核。
- Featured：平台精选。
- Rejected：审核未通过。
- Hidden：违规隐藏。

字段：

- 标题。
- 描述。
- 创作者。
- 使用模板。
- 使用素材。
- 时长。
- 封面。
- 标签。
- 分享链接。
- 数据指标。
- 审核状态。
- 版权风险标记。
- 医疗化表达风险标记。

关键逻辑：

- 作品先属于创作者，再决定是否进入平台内容池。
- 分享不等于入库。
- 入库不自动发生，必须数据达标并人工审核。

### 3.4 Share Page 分享页

分享页是增长入口，也是数据采集入口。

核心动作：

- 打开。
- 播放。
- 收藏。
- 分享。
- 进入创作者主页。
- 举报。

关键数据：

- 访问量。
- 播放开始率。
- 25% 播放率。
- 50% 播放率。
- 90% 播放率。
- 收藏率。
- 分享点击率。
- 外部来源。

关键逻辑：

- 分享页必须比普通播放器更像“作品名片”。
- 分享页要让创作者愿意发出去。
- 分享页数据决定作品是否有资格申请入库。

### 3.5 Creator Profile 创作者主页

创作者主页承接单个作品的外溢流量。

首版能力：

- 头像和昵称。
- 简介。
- 已公开作品。
- 精选作品标识。
- 外部链接。

后续能力：

- 系列作品。
- 订阅创作者。
- 打赏。
- 付费合集。
- 课程或社群承接。

## 4. 关键业务流程

### 4.1 创作流程

```text
选择场景
  -> 选择模板
  -> 调整素材层次
  -> 设置时长
  -> 选择人声开关
  -> 预览
  -> 保存作品
  -> 生成分享页
```

设计重点：

- 不要让用户从空白开始。
- 首屏先问“你要做什么场景”，再进入制作。
- 高级混音能力可以隐藏在进阶面板里。
- 默认结果必须可听，用户只需要微调。

### 4.2 传播流程

```text
作品生成
  -> 分享页生成
  -> 创作者复制链接/二维码/海报
  -> 外部渠道传播
  -> 听众试听
  -> 数据回流
```

设计重点：

- 创作者分享的不是一个文件，而是一个带身份、封面、数据和入库进度的作品页。
- 二维码海报、短试听视频、封面模板是天然付费点。
- 外部传播比早期平台内社区更现实。

### 4.3 入库流程

```text
作品分享
  -> 达到数据门槛
  -> 创作者申请入库
  -> 平台审核版权/质量/表达
  -> 通过后进入精选池
  -> 获得平台推荐标识
```

设计重点：

- 用数据做初筛，用人工做最终判断。
- 入库资格本身就是激励。
- 平台精选要稀缺，不能变成所有作品自动上架。

### 4.4 商业流程

```text
免费制作
  -> 感知限制
  -> 付费解锁创作能力
  -> 分享获得数据
  -> 付费解锁传播和分析能力
  -> 表现好的作品申请入库
  -> 未来进入内容市场/分成
```

关键判断：

- 早期收费对象主要是创作者，不是听众。
- 早期卖的是“做出更好的作品”和“传播得更专业”，不是卖“疗效”。
- 分成和市场要晚做，否则审核、版权、财务、税务、客服复杂度会过早压垮产品。

## 5. 付费痛点设计

### 5.1 创作能力痛点

用户免费版可以完成闭环，但会遇到清晰限制：

- 可用素材少。
- 可用模板少。
- 作品时长短。
- 作品数量有限。
- 音轨层数有限。
- 无高级淡入淡出。
- 无高级人声模板。
- 无高清导出。

付费理由：

> 我想做出更好听、更长、更有层次、更像专业作品的声音。

建议付费项：

- Premium sound assets。
- Premium templates。
- Longer duration。
- More layers。
- Advanced mixing。
- Voice guidance packs。
- High-quality export。

### 5.2 分享传播痛点

创作者在免费版可以分享链接，但缺少传播工具：

- 分享页样式普通。
- 无自定义封面。
- 无二维码海报。
- 无 15 秒试听视频。
- 无品牌水印控制。
- 无外链追踪。

付费理由：

> 我想让作品发出去更像样，更适合朋友圈、小红书、Instagram、社群和私域传播。

建议付费项：

- Custom cover。
- Branded share page。
- QR poster。
- Short preview video。
- Creator landing page。
- External link tracking。

### 5.3 数据反馈痛点

免费版给基础播放量，但不提供深层分析：

- 不知道听众听到哪里退出。
- 不知道哪个渠道带来播放。
- 不知道收藏率是否好。
- 不知道离入库还差多少。
- 不知道同类作品平均水平。

付费理由：

> 我想知道作品有没有打动人，下一首应该怎么改。

建议付费项：

- Completion analytics。
- Referrer analytics。
- Favorite rate。
- Benchmark against similar works。
- Entry-to-featured progress。
- Weekly creator report。

### 5.4 身份与机会痛点

创作者不仅要工具，也想要被看见。

免费版：

- 普通创作者页。
- 普通作品展示。
- 基础入库申请。

付费版：

- 高级创作者主页。
- 系列作品管理。
- 优先审核额度。
- 精选申请提醒。
- 作品集外链。

付费理由：

> 我想把它当成一个正式的声音作品空间，而不是临时生成工具。

注意：

- 优先审核可以买“排队效率”，不能买“精选结果”。
- 平台精选必须由质量和合规决定，不能直接售卖。

## 6. 价格层建议

### Free

适合体验和完成基础闭环。

- 基础素材。
- 基础模板。
- 最长 10 分钟作品。
- 最多 5 个作品。
- 基础分享页。
- 基础播放数据。

目标：

- 让用户真的做出作品。
- 让分享页带来自然流量。
- 让创作者感受到升级价值。

### Creator Plus

适合轻创作者。

- 更多素材。
- 更多模板。
- 最长 30 分钟作品。
- 更多作品空间。
- 自定义封面。
- 二维码海报。
- 基础完播数据。

目标：

- 把“偶尔玩一下”转成“持续发布”。

### Creator Pro

适合专业/半专业创作者。

- 全部素材和模板。
- 最长 60 分钟或更长。
- 高级混音。
- 人声模板包。
- 高级分享页。
- 外链追踪。
- 周报。
- 系列管理。
- 高级创作者主页。

目标：

- 服务有持续经营需求的创作者。

### Platform Market

成熟期再开放。

- 官方精选市场。
- 会员内容池。
- 单曲解锁。
- 打赏。
- 创作者分成。

目标：

- 从工具收入扩展到内容市场收入。

## 7. 平台冷启动策略

### 阶段 1：内部种子内容

平台先制作 20-30 个高质量样例作品，用来：

- 展示工具能力。
- 作为模板示范。
- 填充精选页。
- 教用户什么是好作品。

内容结构建议：

- 睡前放松。
- 情绪安抚。
- 自我接纳。
- 冥想/正念。
- 场景化放松。

这些内容只做陪伴和放松表达，不做医疗承诺。

### 阶段 2：邀请种子创作者

优先找：

- 冥想老师。
- 瑜伽老师。
- 播客主。
- 情绪陪伴博主。
- 生活方式博主。

给他们：

- 免费 Pro 权限。
- 官方精选机会。
- 专属分享页。
- 数据反馈。

目标：

- 先让外部渠道带来真实试听数据。
- 不急着做平台内社区。

### 阶段 3：数据筛选内容池

当有稳定分享数据后：

- 按完播率筛选。
- 按收藏率筛选。
- 按无举报筛选。
- 按场景补齐内容结构。

平台开始形成精选池，但仍然人工审核。

### 阶段 4：市场化

当精选内容池足够稳定后：

- 听众会员。
- 创作者分成。
- 打赏。
- 付费合集。
- 平台抽成。

## 8. 北极星指标与阶段指标

### 北极星指标

每周被外部分享带来的有效试听作品数。

有效试听定义：

- 非创作者本人。
- 播放超过 50% 或超过指定分钟数。
- 无异常刷量迹象。

为什么不用总播放量：

- 总播放量容易被刷。
- 只看播放不能代表放松声景质量。
- 50% 播放更接近作品是否真的可听。

### 创作者侧指标

- 新建作品数。
- 作品完成率。
- 作品分享率。
- 首次分享时间。
- 创作者 7 日复访。
- 付费转化率。
- Pro 用户月发布数。

### 听众侧指标

- 分享页打开率。
- 播放开始率。
- 50% 完播率。
- 90% 完播率。
- 收藏率。
- 二次回访率。

### 平台侧指标

- 申请入库作品数。
- 审核通过率。
- 举报率。
- 下架率。
- 精选作品复听率。
- 素材使用分布。

## 9. 风险与对策

### 9.1 工具做出来但没人分享

原因：

- 分享页不好看。
- 作品不够像样。
- 创作者没有身份感。

对策：

- 优先打磨分享页。
- 提供封面模板和二维码海报。
- 给创作者主页和入库进度。

### 9.2 作品质量低

原因：

- 自由度过高。
- 用户从空白开始。
- 模板没有质量约束。

对策：

- 场景模板优先。
- 默认参数必须好听。
- 平台精选只收数据好且审核通过的作品。

### 9.3 版权风险

原因：

- 用户上传未授权音乐。
- 平台素材授权不清。
- 公版曲谱和现代录音混淆。

对策：

- 首版不开放任意上传。
- 只允许平台素材组合。
- 每个素材记录授权范围。

### 9.4 医疗化风险

原因：

- 创作者为了吸引点击写“治疗失眠”“治愈焦虑”。

对策：

- 标题、描述、标签敏感词过滤。
- 模板内置安全表达。
- 审核时检查医疗化承诺。

### 9.5 过早做分成

原因：

- 以为分成能吸引创作者。

风险：

- 审核复杂。
- 版权复杂。
- 税务和提现复杂。
- App Store 规则复杂。

对策：

- 先做工具订阅。
- 再做传播工具收费。
- 最后做市场和分成。

## 10. 原型前必须回答的问题

在进入 UI 原型前，应先确认：

- 首版主用户是轻创作者还是专业创作者？
- 首版是否允许用户上传自己的声音？
- 免费版作品时长限制是多少？
- 分享页是否允许匿名访问？
- 收藏是否需要登录？
- 入库门槛用哪些指标？
- 平台精选是否人工审核？
- 首版是否做听众首页，还是只做分享页和创作者工作台？
- 首版是否做订阅付费入口，还是先把付费点展示为 locked 状态？

建议默认答案：

- 主用户先选轻创作者。
- 首版不允许任意上传，只用平台素材。
- 免费版最长 10 分钟。
- 分享页允许匿名访问。
- 收藏需要轻登录。
- 入库门槛用试听、收藏、50% 完播、无举报。
- 平台精选人工审核。
- 首版先做分享页和创作者工作台，不急着做复杂听众首页。
- 付费入口可以先做 locked 状态，用于验证痛点。
